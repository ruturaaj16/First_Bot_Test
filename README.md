# Custom Discord Utility Bot 🤖🎮

A lightweight, automated Discord bot built with Node.JS. Designed to monitor channel activity, process specific text commands, and execute automated replies and reactions to enhance server engagement.

---

## 🚀 Features
* **Keyword Triggers:** Scans incoming messages and automatically replies to specific user commands.
* **Automated Reactions:** Interacts with users by reacting to designated messages with custom emojis.
* **Cloud Ready:** Structured to run continuously on cloud platforms (previously hosted on Heroku) using a secure bot token.

---

## 🛠️ Tech Stack
* **Runtime:** Node.JS
* **Framework:** Express.JS 
* **API Wrapper:** Discord.js (or standard Discord API webhooks)

---
